# 迷宫模拟器 052

访问：https://kubona.github.io/migong/

每种怪物独立搜索，保留高度与速度各有优势的配装。先对无序技能集合粗筛、二分搜索和楼层边界采样，再对优势候选枚举合法技能顺序、独立复核。默认100场粗筛、1000场等级测试、5000场最终复核。

单场仍需达到用户设置的目标胜率。失败按120秒计时，胜利计实际耗时。房间至多尝试两次，双方每次重新开始；显示通过概率 1-(1-p)² 和房间平均耗时 M×(2-p)，其中 M 为包含失败惩罚的单场平均耗时。房间耗时可超过120秒，最高240秒。结果是有限样本估计，不保证全局最优或整层必定通关。

楼层上限和共同等级用于安排比较，结果绑定具体怪物等级，不把不同等级样本混合成层内平均。挑战阈值由结果确定，不作为搜索区间输入。

导入角色与游戏数据后，可在折叠的角色分类中修改战斗等级、装备强化、技能、触发条件、增益、迷宫升级、补给箱、战斗房屋和成就。开始前自动应用有效修改，可恢复原导入数据。

计算在本机浏览器运行，数据不上传。任务可暂停和恢复，但旧版本断点不能跨版本恢复。本版移除旧搜索与排名分支、无用图集和额外战斗明细汇总。

网页版手动选择角色与游戏数据文件；Windows本地版也支持原有游戏数据桥接。运行包不含角色数据、测试夹具或构建缓存。第三方许可见 THIRD_PARTY_NOTICES.md。
