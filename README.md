# 迷宫模拟器 054

访问：https://kubona.github.io/migong/

054增加各子模块的折叠入口，删除独立装备预设来源模块，将技能轮换开关合并到固定技能。

角色编辑：总战斗等级优先读取导入值，调整分项后自动计算；九个方向预设分别显示从持有装备解析的具体装备与强化，允许单独调整；技能按类别排序，支持全选、反选、清空选择与批量等级；删除技能触发条件编辑；增益响应式并排；成就只显示类别名称、效果和启用勾选。

默认固定技能：魔法元素增幅，以及第四号位对应元素的零冷却技能；物理狂速、狂暴；宝箱怪尖刺防护、惩戒。实际候选遵循这些约束。原始游戏数据不会被修改。

沿用053的实时进度、暂停恢复、宽窄屏布局和可选尝试次数。房间最多尝试1～10次，默认2次。单场胜率p、含120秒失败惩罚的平均耗时M、次数n对应通过概率Q=1-(1-p)^n、房间平均耗时M×Q/p；p=0时平均次数为n。单场胜率门槛不变。

每种怪物独立搜索，保留高度与速度各有优势的候选，默认100场粗筛、1000场等级测试、5000场最终技能顺序复核。结果是有限样本估计，不保证全局最优。旧版本断点不能跨版本恢复。

计算在本机浏览器运行，角色数据不上传；发布包不含用户数据、测试文件或构建缓存。第三方许可见THIRD_PARTY_NOTICES.md。

界面组织参考：https://github.com/tabler/tabler 。总战斗等级计算参考：https://milkywayidle.wiki.gg/wiki/Combat_Level 。
