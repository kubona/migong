# 迷宫模拟器 053

访问：https://kubona.github.io/migong/

053重做宽屏双栏和响应式布局，统一中文字体、标题层级、控件尺寸及分区。角色编辑仍按需展开。模拟过程持续显示怪物、阶段、配装、等级、场数、时间和线程状态，支持暂停、停止和恢复。

房间最多尝试次数可选1～10次，默认2次，保存进任务与结果。每次双方重新开始，失败计120秒，胜利计实际耗时。单场胜率p、含失败惩罚的平均耗时M、尝试上限n对应：通过概率Q=1-(1-p)^n，房间平均耗时=M×Q/p，p=0时为M×n。单场胜率门槛不改变；有限样本结果不保证真实全局最优。

沿用052独立搜索与高度/速度优势候选保留。默认100场粗筛、1000场等级测试、5000场最终复核。楼层边界与共同等级组织测试，阈值由结果决定。早期不枚举技能顺序，优势候选最终复核合法顺序。

网页版手动导入角色和游戏数据，本地版支持原有数据桥接。计算在访问者浏览器运行，角色数据不上传。053使用新任务签名，旧版断点不能直接恢复。

界面组织参考开源项目Tabler的卡片、表单分区及响应式布局：https://github.com/tabler/tabler ，https://docs.tabler.io/ui/components/card 。使用本站原生样式实现，没有引入远程依赖。
